# 算法竞赛题解合集

本仓库收录了蓝桥杯、天梯赛、洛谷等各类算法竞赛的真题与练习题 C++ 实现，便于查阅和复习。

## 目录结构说明

- 根目录下为各类题目的 C++ 源文件（.cpp）及其可执行文件（.exe）。
- 以 `pXXXX` 命名的文件为洛谷题目编号。
- 以 `L1-XXX`、`L2-XXX` 命名的为天梯赛题目。
- 以数字命名的文件夹（如“十二”、“十三”等）为蓝桥杯题目练习。
- `天梯赛/`、`天梯模拟赛/` 等为天梯赛相关题目专用文件夹。
- 其他如 `毛/`、`tts/` 等为自定义分类。

## 示例

```
├── p1048采药.cpp         # 洛谷 P1048 采药
├── L1-002打印沙漏.cpp    # 天梯赛 L1-002
├── 十二/
│   ├── 1.cpp
│   ├── 2.cpp
│   └── ...
├── 天梯赛/
│   ├── L1-009.cpp
│   └── ...
└── readme.md             # 项目说明文件
```

## 使用说明

- 直接用 C++11 及以上标准编译运行。
- 可根据题号或文件夹快速定位所需题目源码。

## 适用人群

- 算法竞赛选手
- 蓝桥杯、天梯赛、洛谷刷题者
- C++ 算法学习者
